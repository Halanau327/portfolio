# Portfolio Website

Modern portfolio website showcasing projects, skills, testimonials, and contact information.

## Features

- 🎨 **Modern UI/UX** - Built with styled-components for a clean, responsive design
- 📱 **Fully Responsive** - Optimized for all device sizes
- 🚀 **Smooth Scrolling** - Seamless navigation between sections
- 🎯 **Project Filtering** - Filter projects by type (All, Landing page, React, SPA)
- 🎭 **Interactive Elements** - Typewriter effect, sliders, and animations
- ♿ **Accessible** - ARIA labels and semantic HTML

## Tech Stack

- **React 18** - UI library
- **TypeScript** - Type safety
- **Styled Components** - CSS-in-JS styling
- **React Scroll** - Smooth scrolling navigation
- **Swiper** - Touch slider component
- **Typewriter Effect** - Animated text typing
